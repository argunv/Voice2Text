# Проект Voice2Text

## Описание
Проект представляет собой телеграм-бота, с использованием модели распознавания речи, который переводит аудиосообщения в текстовые сообщения.

## Состояние проекта
Проект находится в стадии разработки. Данная ветка `dev` является рабочей и может содержать нестабильный код.

## Стек технологий
- Python
- Telegram API
- Minio (S3)
- openai-whisper
- Docker
- poetry

## Установка
1. Склонируйте репозиторий
2. Установите зависимости
```bash
poetry install
```
3. Создайте файл .env и укажите в нем переменные окружения, как в файле .env.example
4. Запустите проект
```bash
docker-compose up
```
